## Environmental Data Logger – Power Section

A practical KiCad PCB design project focused on the power section of an Environmental Data Logger.

## Project Purpose

This project was created to learn KiCad through practical implementation and to strengthen PCB design and circuit simulation skills for final-year BE projects and upcoming competitions.

## Project Focus

- Power Section Design
- PCB Design
- Circuit Simulation
- KiCad Workflow

## Tools Used

- KiCad
- SPICE Simulation

This project is part of my ongoing learning in PCB Design and Hardware Development.
